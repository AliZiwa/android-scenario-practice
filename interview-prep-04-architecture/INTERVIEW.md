# Assignment 04: the questions this diff invites

Answer each out loud in under two minutes. These are the follow-ups a Staff interviewer would ask after reading your PR.

1. Walk me through `DefaultPartsRepository.adjust` from line 49 to line 65 with a 422 `insufficient_stock` response. Which line throws, which `catch` receives it, and what message does the technician see? Then: your test on line 118 of `DefaultPartsRepositoryTest` accepts either string. When you wrote that `||`, what did you believe the code did?
2. The ADR says `Author: AI Assistant` and is dated October 25. The assignment was published October 27. In your own words, no document in front of you: what are the three layers, what is the one rule between them, what enforces it, and which file would you change first if a sync queue had to land next sprint?
3. `PartsListViewModel.uiState` is `combine(observeParts(), query, errorMessage).stateIn(viewModelScope, WhileSubscribed(5000), Loading)`. Explain what `WhileSubscribed(5000)` does when the user rotates the phone, what happens to `errorMessage` during those five seconds, and why `PartsListState.Error` can never be emitted by this flow.
4. The detail screen gets `selectedPartId` as a composable parameter and passes it into `vm.load(id)` from `LaunchedEffect(Unit)`. On rotation the Activity is recreated and the ViewModel survives. How many collectors of `observePart` exist after one rotation? After three? Show the version where the id reaches the ViewModel through `SavedStateHandle` and `toRoute`, and `uiState` is a single `stateIn`.
5. `PartDetailViewModel.adjust` sets `uiState.value = Error(...)` on failure. The part was in `Loaded` a moment ago. Where did it go, what does the technician see, and what are the two ways to model "a thing that loaded, plus a message about the last action" so the second never erases the first?
6. `catch (e: Exception)` wraps `repository.adjust(...)` in a coroutine on `viewModelScope`. The user presses Back mid-request. Name the exception that arrives, what your `catch` does with it, what `busy.value = false` in `finally` then does to a ViewModel that is being cleared, and why I have written this comment on three assignments.
7. `lowStock = quantity <= minQuantity` is on line 32 of `PartEntity.kt` and line 36 of `PartsService.kt`. Product changes the rule to "below minimum, or at minimum and no restock in 30 days". Which files change, which tests catch a miss, and what is the one-line Kotlin that makes this rule exist in exactly one place?
8. `require(reason.isNotBlank()) { "Reason required" }` throws `IllegalArgumentException`, and the ViewModel shows `e.message`. A French localisation lands. Trace what breaks, then design the sealed type that crosses the repository boundary so that the ViewModel owns every string and the repository owns none.
9. `PartsRepository` declares `listParts()` and `getPart(id)`. Nothing calls them. Both hit the network and skip Room. What does their presence on the interface tell a new engineer about the source of truth, and what would you say in review if someone used `getPart` for the barcode-scan feature?
10. `OfflineState` lives in `domain`, is a `MutableStateFlow<Boolean>` wrapper, is written by a composable and read by an OkHttp interceptor. Defend the package choice for sixty seconds, then argue the other side: where does a test-only switch belong, and how would the architecture test know?
11. The two validation tests prove the right exception and message. The contract says "before any network call". What single assertion is missing, what is `MockWebServer.requestCount`, and what regression would the test as written fail to catch if someone reordered the `require` lines below the service call?
12. `refreshParts network failure leaves Dao unchanged` wraps the call in `try { } catch (e: Exception) { assertTrue(e is IOException) }`. Describe a code change to `refreshParts` that makes this test pass while the contract is broken. What does `assertThrows` give you that this shape does not?
13. `launch(Dispatchers.IO)` in both ViewModels calls a repository whose underlying Room and Retrofit suspend functions already switch threads. What does the extra dispatch cost, what does it do to the order of `busy.value = true` and the first `uiState` update, and when is injecting a dispatcher into a ViewModel the right call versus making the repository main-safe?

Commit 7 added the whole `domain` package, every test, and the ADR in 464 lines. Reconstruct, on a whiteboard, the seven commits this branch should have had, and say which of them you could have cut as a PR on its own.
